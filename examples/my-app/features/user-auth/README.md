# ユーザー認証

## 概要

メールアドレスとパスワードでログインし、認証成功後にダッシュボードへ遷移する。

## スコープ

| 含む | 含まない |
|------|----------|
| メール・パスワードログイン | ソーシャルログイン |
| ログイン画面 | パスワードリセット |
| JWTトークン発行 | ユーザー登録 |

## 関連一覧

| 種別 | ID | 名前 |
|------|-----|------|
| 画面 | SCR-AUTH-001 | ログイン画面 |
| API | API-AUTH-001 | ログイン |
| DB | TBL-USERS | users |
| コンポーネント | CMP-AUTH-001 | LoginForm |

## 依存機能

- なし

## 受け入れ条件

- [ ] REQ-AUTH-001: 正しい認証情報でログインしダッシュボードへ遷移できる
- [ ] REQ-AUTH-002: 誤った認証情報でエラーメッセージが表示される
