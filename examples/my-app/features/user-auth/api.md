# API設計: ユーザー認証

## API一覧

| API-ID | メソッド | パス | 概要 | 主な入力 | 主な出力 | 認証 |
|--------|----------|------|------|----------|----------|------|
| API-AUTH-001 | POST | /api/v1/auth/login | ログイン | メールアドレス、パスワード | JWTトークン、ユーザー概要 | 不要 |

## エラー

| 条件 | HTTP | ユーザーへの表示 |
|------|------|------------------|
| バリデーションエラー | 400 | 入力内容を確認してください |
| 認証失敗 | 401 | メールまたはパスワードが違います |
| サーバーエラー | 500 | しばらくしてから再度お試しください |

## API-AUTH-001 補足

- 成功時: トークン有効期限は24時間（要確認）
- 失敗時: ブルートフォース対策は将来対応（スコープ外）
