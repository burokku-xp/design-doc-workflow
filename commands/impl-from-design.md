---
name: impl-from-design
description: Implement a feature from design docs and a GitHub Sub-Issue following clean-code rules.
---

Use the `impl-from-design` skill with a Sub-Issue number or feature context.

Example: Issue #123 を設計書参照して実装して

Applies `design-readonly` and `clean-code` rules. Opens implementation PR via GitHub MCP or gh CLI.
